# CyberArena

**Browser hacking games — no installs, no sign-up.**
Live at **[cyberarena.in](https://cyberarena.in)**

CyberArena is one site with one shell and multiple operations. Everything
runs entirely in the browser (pure front-end): boot a terminal, work the
case, take the flag.

## 🗺️ Site map

| Path | What it is |
|---|---|
| `/` | **The Lobby** — operations board, pick your mission |
| `/secure-shell/` | **Secure Shell** — the original CyberArena terminal game (Case #114, Meridian Holdings) in the unified Ghost shell |
| `/breach-protocol/` | **Breach Protocol: Operation Glass Ledger** — Mission 01 against Meridian Finance (nmap → sqlmap → hashcat → ssh → flag), trace meter, scoring, XP |

Both games share the same status strip, wordmark and design system, so new
operations slot into the board as new cards + folders.
